# Soenneker.Quark.Enums.FontWeights

## Install

```bash
dotnet add package Soenneker.Quark.Enums.FontWeights
```

## What you get

- `FontWeightKeyword` — Typed values for the CSS font-weight property in .NET enumeration form.
